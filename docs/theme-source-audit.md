# Authored color-source audit

Omarchy's theme selector is the source for graphical colors. Its generated
current-theme files are consumed where available; terminal applications use
ANSI names so Ghostty's generated palette carries the selected theme through.

## Removed or redundant outputs

- `env/.config/omarchy/themed/shell.toml.tpl` duplicated the packaged template
  except for the user's bar sizing; the minimal `shell.toml` now holds only
  that geometry.
- `env/.config/omarchy/themed/tmux-palette.sh.tpl` and the generated tmux
  palette helper were removed. Tmux now resolves named ANSI colors through the
  terminal palette.
- The static Ghostty palette file and Alacritty sample were removed. Ghostty
  uses the stock generated template output.

The color scan across authored `env/` found fixed hex/truecolor values only in
`env/.config/omarchy/themes/rose-pine-dark/colors.toml`, the selected theme's
own palette source. Changes are authored in the worktree only. Before a later
deployment, review the envctl plan and explicitly prune obsolete live copies
only after backing them up. No live paths were deleted in this pass.
